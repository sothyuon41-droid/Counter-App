Counter App

A simple counter app built in HTML‚ CSS‚ and JavaScript with no additional frameworks․ Sample skills demonstrated in this project include basic DOM navigation and manipulation with CSS Flexbox layout and other methods‚ along with changing page content based on user interaction․

Live Demo
🔗 [Live App Demo](https://sothyuon41-droid․github․io/Counter App/)

Features
- Increment and Decrement: Slowly increase or decrease the counter's value․
- Quick reset: Click a button to set the count to 0․
- Clean interface design using a centered layout with Flexbox and stylized buttons and hover responses․

Built With
- HTML5‚ Semantic design
- CSS - Flexible box layouts‚ pill buttons with rounded edges‚ animations
- JavaScript (ES6)‚ Adding events and making changes to the DOM
